Every SVG is a verbatim file from the published package. The package's original
LICENSE is copied beside this file. The manifest records assetId, code, name,
source, license, SHA-256, path and selectable status.

Special RGI mappings:
- `EA` (Ceuta & Melilla) resolves to `es.svg`; Unicode emoji sources document
  that the EA flag uses the same flag as Spain.
- `TA` (Tristan da Cunha) resolves to `sh-ta.svg`; the package's own
  `country.json` names `sh-ta` as Tristan da Cunha.
- `GB-NIR` is included as a football home-nation special flag.

Unicode-only RGI codes without a local SVG in this fixed package:
- `AC` (Ascension Island)
- `CQ` (Sark)

These two keep an exact Unicode fallback and are marked `flagAssetId: null` in
NATION_REFS; no name-similar or order-based substitution is used.
